## Description
Analyze temporal data patterns including trends, seasonality, autocorrelation, and forecasting for time series decomposition, trend analysis, and forecasting models.

## Included Skills
- `time-series-analysis` - Time series analysis guide

## Usage
When working with time series data, this skill provides guidance on:
- Time series decomposition (trend, seasonal, residual)
- Stationarity testing (ADF test)
- ARIMA/SARIMA modeling
- Exponential Smoothing
- Forecast evaluation metrics (MAE, RMSE, MAPE)
- ACF/PACF analysis
