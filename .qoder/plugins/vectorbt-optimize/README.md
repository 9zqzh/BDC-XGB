## Description
Optimize trading strategy parameters using VectorBT. Tests parameter combinations and generates heatmaps for strategy performance analysis.

## Included Skills
- `vectorbt-optimize` - VectorBT parameter optimization

## Usage
When optimizing trading strategy parameters with VectorBT, this skill provides:
- Parameter grid search with OpenAlgo ta indicators
- Multiple performance metrics tracking
- Plotly heatmap generation
- Strategy vs benchmark comparison
- Plain-language result explanations

### Example
`/vectorbt-optimize ema-crossover RELIANCE NSE D`
`/vectorbt-optimize rsi SBIN`
