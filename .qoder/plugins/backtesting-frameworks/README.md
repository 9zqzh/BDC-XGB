## Description
Build robust backtesting systems for trading strategies with proper handling of look-ahead bias, survivorship bias, and transaction costs.

## Included Skills
- `backtesting-frameworks` - Backtesting frameworks guide

## Usage
When developing trading strategy backtests, this skill provides guidance on:
- Avoiding common backtesting biases (look-ahead, survivorship, overfitting)
- Proper backtest structure (train/validation/test)
- Walk-forward analysis
- Transaction cost modeling
- Monte Carlo analysis for robustness
