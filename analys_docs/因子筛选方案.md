## 特征筛选流程建议

本项目的目标是预测未来一周沪深300成分股中收益最高的股票组合。因此，特征筛选不能只看单因子的统计显著性，最终应以滚动窗口下模型的 TopK 和组合收益表现为准。

### 1. 单因子 Rank IC / ICIR 初筛

在每个交易日截面上，计算因子值与未来一周收益之间的 Rank IC，并汇总 IC 均值、IC 标准差和 ICIR。

建议保留以下因子：

- IC 均值大于 0，或经济含义明确且方向稳定；
- ICIR 相对稳定；
- 在不同时间区间中方向没有频繁反转；
- 因子方向符合金融逻辑。

该步骤用于剔除明显无效、噪声较大的单个因子。ICIR 只用于初筛，不作为最终保留依据。

### 2. 按因子族分组

将通过初筛的特征划分为因子族：

- 量能/流动性；
- 区间位置/突破；
- 动量趋势；
- 波动风险；
- 估值/基本面，如数据中存在。

后续以因子族为单位进行消融、置换和协同效应测试。

### 3. Refitting 分组消融验证

对不同特征组重新训练模型，比较模型在滚动窗口中的表现。

建议实验：

- `baseline`：使用全部候选特征；
- `volume_only`：只使用量能/流动性特征；
- `range_only`：只使用区间位置/突破特征；
- `momentum_only`：只使用动量趋势特征；
- `no_volume`：删除量能/流动性特征；
- `no_range`：删除区间位置/突破特征；
- `no_momentum`：删除动量趋势特征；
- `selected_features`：使用筛选后的候选特征集。

判断逻辑：

- 删除某因子族后 `final_score` 明显下降，说明该因子族有增量价值；
- 删除某因子族后 `final_score` 上升，说明该因子族可能引入噪声；
- 只使用某因子族也能取得稳定正收益，说明该因子族具有独立预测能力。

Refitting 是本项目判断因子族是否值得保留的主要方法，因为它直接反映重新训练后的实际选股效果。



### 4. 核心因子族的双因子 25 组 / 协同效应

双因子测试应放在 Refitting 分组验证和 Grouped Feature Importance 之后，只对已经证明有独立价值的核心因子族进行。

例如：

- 动量 × 量能；
- 区间突破 × 流动性；
- 动量 × 波动；
- 区间突破 × 动量。

将两个因子分别按截面值分成 5 组，形成 25 个组合，观察高分组、低分组和多空组合的未来一周收益。

重点判断：

- 双因子最优组合是否优于对应的单因子组合；
- 收益是否具有较稳定的单调性；
- 协同效应是否在多个时间窗口中重复出现；
- 加入交互特征后，模型滚动 `final_score` 是否提升。

只有当双因子组合的多空收益、联合单调性和相对最佳单因子的增量收益均为正时，才将其交互特征加入滚动验证候选集。

双因子 25 组首先用于发现和验证协同关系；只有当其结果稳定，并且加入模型后改善滚动窗口表现时，才考虑构造交互特征或保留相关因子组合。

### 5. 滚动窗口验证时间稳定性

所有特征筛选实验都应在时间滚动框架下进行，不能只依赖单一验证集。最终比较以下指标：

- 滚动窗口平均 `final_score`；
- `final_score` 标准差；
- TopK Hit Rate；
- Top5 组合真实收益；
- 不同窗口中指标是否稳定为正。

因子筛选应在每个滚动窗口的训练数据内完成，不能使用验证窗口的信息，以避免时间泄漏。

### 6. 最终评分标准

最终特征是否保留，以滚动窗口平均 `final_score` 为主：

```text
最终评分 = mean(rolling final_score)
```

实际候选筛选规则为：

1. 优先 `final_score_mean` 更高的方案；
2. `positive_window_ratio >= 0.5`；
3. `final_score_std` 不明显高于 baseline，默认不超过 baseline 标准差的 1.25 倍。

如果没有候选方案同时满足第 2、3 条，则保留全部候选并仅按 `final_score_mean` 排序。`instrument` 不作为默认模型特征，含该字段的方案只作为对照实验。

同时检查结果稳定性和实际选股指标。优先保留以下特征或因子族：

- 平均 `final_score` 更高；
- 多数滚动窗口表现为正；
- 删除后模型性能明显下降；
- TopK Hit Rate 和 Top5 组合收益同步改善；
- 结果波动没有明显增大。

最终流程为：

```text
单因子 Rank IC / ICIR 初筛
-> 因子族分组
-> Refitting 分组消融
-> 核心因子族双因子 25 组 / 协同效应
-> 构造候选特征集
-> 滚动窗口 final_score 最终验证
```
